# sooraj171.github.io

Personal portfolio for Sooraj Ramachandran — quality engineering, STAF frameworks, and AI evaluation.

Live site: https://sooraj171.github.io

## Deploy

This repository is intended to be published as a GitHub Pages user site.

1. Push the contents of this folder to the root of `sooraj171/sooraj171.github.io`.
2. In **Settings → Pages**, set **Deploy from a branch** to `main` / `(root)`.
3. Wait for deployment. The site will be available at https://sooraj171.github.io.

Static HTML/CSS/JavaScript only — no build step required.

## Customize

- Update copy and project links in `index.html`
- Adjust colors, type, and layout in `assets/styles.css`
- Keep `assets/script.js` for year stamp and light entrance motion
