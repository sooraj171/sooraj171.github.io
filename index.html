01 Agentic framework · 15k+ downloads

STAF.UI.API

An agentic automation framework for Selenium UI and API testing. It combines enterprise automation—reporting, parallel execution, Excel/DB helpers, and accessibility—with built-in agent skills and Model Context Protocol (MCP) servers for Selenium and Azure DevOps. Coding agents can generate, analyze, and operate tests through a ready-made tool surface, and the platform stays agent-ready for additional MCP servers as workflows expand.

02 Agentic framework · Playwright

STAF.Playwright

The Playwright counterpart of the STAF agentic stack—an agentic automation framework for modern browser testing with multi-runner support, HTML reporting, and API utilities. It includes built-in agent skills, a Playwright MCP server, and Azure DevOps MCP integration so agents can author and operate tests in CI-connected workflows, with room to plug in more MCP agents over time.
